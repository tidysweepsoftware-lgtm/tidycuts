# Fonts

All fonts here are under the SIL Open Font License (see the `OFL-*.txt` files)
or the Apache License 2.0 (`APACHE-LICENSE.txt`).

`Inter-Variable.ttf` has had its private-use (U+E000–U+F8FF) character map
entries removed, so the editor's icon font is used for those code points.
The glyph outlines are unchanged.

Fonts that ship as variable fonts upstream were cut to one fixed weight with
fontTools (arLib.instancer), so they open on a useful weight; the outlines
are unchanged. This was done only for families whose licence has no Reserved
Font Name: Montserrat, Outfit, Sora, Space Grotesk, Unbounded, Bricolage
Grotesque, Big Shoulders Display, Teko, Oswald, Cinzel, Caveat and JetBrains
Mono. Every other new font is the unmodified upstream file. Each family's
licence text is OFL-<family>.txt.
