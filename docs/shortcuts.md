# Keyboard shortcuts

| Keys | Action |
| --- | --- |
| Space | Play / pause |
| ← / → | Previous / next frame |
| Shift+← / Shift+→ | Back / forward one second |
| ↑ / ↓ | Previous / next cut |
| Home / End | Jump to start / end |
| F or Alt+Enter | Full-screen preview (Esc leaves) |
| Ctrl+B | Split at the playhead |
| Alt+[ / Alt+] | Trim the clip's start / end to the playhead |
| Del / Shift+Del | Delete / ripple delete |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste |
| Ctrl+D | Duplicate |
| Ctrl+Alt+D | Detach audio |
| Alt+C | Crop and zoom |
| Ctrl+R | Speed |
| Ctrl+T | Add a title |
| Ctrl+A | Select all |
| N | Snapping on / off |
| Ctrl+= / Ctrl+- | Zoom the timeline in / out (also Ctrl+mouse wheel) |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+I | Import media |
| Ctrl+E | Export |
| Ctrl+S / Ctrl+Shift+S | Save / save as |
| Ctrl+O / Ctrl+N | Open / new project |
| Ctrl+, / Ctrl+Shift+, | Preferences / Project Settings |

(On macOS use ⌘ instead of Ctrl.)
